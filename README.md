# Student-Marks-Test-Assignment-Exam
🎓 Student Marks Management System (Python)
A Python-based marks calculation program for managing students’ examination, test, and assignment scores.
This tool calculates totals, averages and can be adapted for grading systems. Designed for ease of use in academic environments.

✨ Features
📥 Input – Capture student names and marks for exams, tests, and assignments.
🧮 Automatic Calculations – Compute total marks and average scores.
📊 Grade Assignment – Option to categorize results into grades (e.g., A, B, C).
📄 Display Results – Print out formatted results for each student.
⚡ Simple & Lightweight – Runs in the terminal with no extra dependencies.

🖥️ Tech Stack
Language: Python 3
Environment: Terminal / Command-line
Dependencies: None (built with standard Python libraries)
